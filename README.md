# Arpit — AI / ML & Web3

Personal portfolio, prepared for GitHub Pages at https://arpitmisra.github.io.

The website uses plain HTML, CSS, and JavaScript. No build step or dependencies are required.

## Editing

- Edit `index.html` to update project, education, experience, and contact content.
- Edit `resume-content.js` to supply a résumé summary or public PDF URL. An empty summary keeps the current default.
- To serve a PDF from this repository, upload `resume.pdf` and set the URL to `resume.pdf`.

## Hosting

Publish the public repository `arpitmisra/arpitmisra.github.io` through GitHub Pages, using the `main` branch and repository root. `.nojekyll` keeps the site buildless.

This repository contains only the public site; no hosting credentials are required in its files.
